## 1. Opis moda (pole "Description")

```
BETTER SPECIALISTS UI BY NAJANE

When you place a specialist, every workable tile repeats the same numbers: the same
upkeep, the same base yield, over and over. The one thing that actually matters -
how this tile differs from the others - gets buried in the noise.

This mod pulls the shared part out. A "Common Specialists Yields" panel states once
what any specialist in this city gives and costs. The tiles on the map then show only
how they deviate from it. A tile matching the common value shows nothing at all; a tile
giving +5 Production where +3 is common shows just "+2".


WHAT YOU GET

- A "Common Specialists Yields" panel, shown both on the "Choose a tile" screen and in
  the "Add specialist" view.
- A clean map, where only real differences appear above the hexes.
- Negative yields on hover only. Upkeep is usually identical everywhere, so it appears
  on the tile under your cursor instead of cluttering every hex.
- Hold Tab at any time to switch back to the game's original, untouched display. The
  key is rebindable under Options -> Accessibility -> Keyboard and Mouse ->
  Configuration, listed as "Better Specialists UI: alternative view". The on-screen
  hint always names whichever key you have bound.
- Rural tiles are left alone. Improvement and expansion tiles keep their normal display.


OPTIONS

Found under Options -> Mods. All of them default to off:

- Always show negative yields
  Shows negatives on every tile, not just the hovered one.

- Show original yields by default
  Inverts the key: the game's own view becomes the default, and holding the key shows
  the differences instead.

- Do not aggregate negative yields
  Keeps costs out of the common value on the map, so each tile shows its full negative
  yields rather than only the difference. The panel still lists them.

- Do not aggregate positive yields
  The mirror image: each tile shows its full positive yields even when every tile has
  the same ones.

- Show only yields with a common value
  Hides yield types that specialists do not affect from the Common Specialists Yields
  panel.

- Show everything on hover
  The tile under the cursor shows its complete, unmodified yields instead of the
  difference, so the cursor works as a magnifying glass over an otherwise reduced map.


COMPATIBILITY

- Interface only. No game rules, values or balance are changed - the mod only changes
  how existing numbers are presented.
- Does not affect saved games. Safe to add or remove at any time.
- Works by decorating the game's own panels instead of replacing its files, so it
  should coexist with other UI mods.
- Tested alongside City Hall: its building slot icons above specialist tiles stay
  visible while this mod's view is active.


LANGUAGES

English, Polish, German, Spanish, French, Italian, Portuguese (BR), Japanese, Korean,
Simplified Chinese, Traditional Chinese, Ukrainian.


SOURCE CODE

The mod is open source and free to reuse:
[paste your GitHub link here]


SUPPORT

If you find this useful and want to buy me a coffee:
[paste your donation link here]


DISCLAIMER

This entire mod was generated by Opus 5, a model by Anthropic.

I allow anyone to use this mod freely as a basis for creating their own. Take it apart,
copy from it, build on it - no permission needed.
```

Better Specialists UI by Najane - a UI-only mod that makes specialist placement
readable. Highlights:

## 2a. Changelog — wersja 1.3

```
VERSION 1.3

Key binding
- The alternative view is now a real key binding. It is listed under
  Options -> Accessibility -> Keyboard and Mouse -> Configuration as
  "Better Specialists UI: alternative view" and can be rebound to any key.
- The default is now Tab. It used to be hardwired to Shift, which clashed with other
  UI mods reacting to the same key.
- The on-screen hint names the key that is actually bound and follows any rebinding,
  instead of always saying "Shift".
- The binding entry is translated in all 12 languages.

Compatibility
- City Hall's building slot icons above specialist tiles are drawn again while this
  mod's view is active. Until now they only reappeared while the original view was on
  screen, because this mod replaced the drawing step City Hall extends.

Changes
- "Show positive yields only" is now called "Do not aggregate positive yields" and sits
  directly under its negative counterpart, which it mirrors exactly. It no longer
  overrides "Always show negative yields" - each option now does one thing.
- "Show full yields on hover" is now "Show everything on hover".
- Icons in the Common Specialists Yields panel are centred with even spacing instead of
  being stretched across the panel when some of them are filtered out.

Fixes
- "Show positive yields only" did nothing when a yield was the same on every tile. It
  now shows such yields in full, which was the point of the option.
```

## 2b. Changelog — wersja 1.2

> Uwaga: 1.1 nigdy nie zostało opublikowane (w `.modinfo` była wciąż `version="1"`),
> więc te notatki obejmują **wszystko od 1.0** — gracz aktualizuje się właśnie z niej.

```
VERSION 1.2

The mod is now called "Better Specialists UI by Najane". Nothing about how it works
changed with the name - your settings and subscription carry over.

New options
- Show full yields on hover
  While the cursor rests on a tile, that one tile shows its complete, unmodified
  yields instead of the difference. The rest of the map stays reduced, so the cursor
  works as a magnifying glass. Off by default.
- Show positive yields only
  Keeps negative values off the map entirely; they still appear on the tile under the
  cursor. Takes precedence over "Always show negative yields". Off by default.

Changes
- The panel heading is now "Common Specialists Yields" instead of "Common Yields",
  matching the name used in the options screen. Updated in all 12 languages.

Performance
- The common-yield calculation, per-tile yield deltas and district lookups are now
  cached and recomputed only when the underlying data actually changes (a specialist
  being placed, or entering a different city). Previously the whole calculation ran
  again from scratch for every single tile, which meant hundreds of redundant engine
  queries each time the map was redrawn.
- Moving the cursor between tiles now repaints only the two tiles involved instead of
  the entire map layer. The old full repaint also re-walked the city's whole growth
  domain on every cursor movement.
- The hover repaint is skipped completely when it cannot change anything: when
  "Always show negative yields" is enabled, or while the original view is being shown.
- Removed a per-tile allocation from the drawing loop.

Fixes
- Disabled diagnostic logging that was accidentally left enabled in 1.0. It wrote one
  line per tile into the game's UI log, where the entries appeared as errors.

Changes
- The panel heading is now "Common Specialists Yields" instead of "Common Yields",
  matching the name used in the options screen. Updated in all 12 languages.
```

## 2c. Changelog — wersja 1.0

```
VERSION 1.0 - INITIAL RELEASE

Common Yields panel
- Added a "Common Yields" panel that shows, once per city, what any specialist gives
  and costs there.
- The common value is the part every specialist option shares: for each yield, the
  value closest to zero across all specialist tiles. A yield that only some tiles
  produce has no common part and is left out.
- Both a specialist's yield gain and its upkeep are taken into account.
- The panel appears in two places: at the bottom of the "Choose a tile" overview and
  at the top of the "Add specialist" view.
- Only urban tiles (Urban and City Center districts) are counted. Rural expansion
  tiles are excluded from the calculation.

Map display
- Tiles now show only their deviation from the common value instead of the full
  figures. A tile matching the common value shows no yield pill at all.
- Negative yields are shown only on the tile under the cursor by default.
- Rural and expansion tiles keep the game's original display, untouched.
- Specialist pips and blocked-tile markers are unchanged.

Shift toggle
- Holding Shift switches to the game's original, unmodified display.
- The panel hint updates live to show where Shift will take you: "Shift -> default
  view" or "Shift -> yield differences".

Options (Options -> Mods)
- Always show negative yields (default: off)
- Show original yields by default (default: off)
- Do not aggregate negative yields (default: off)
- Show only yields with a common value (default: off)
- Settings persist between sessions.

Localization
- Full translations in 12 languages: English, Polish, German, Spanish, French,
  Italian, Portuguese (BR), Japanese, Korean, Simplified Chinese, Traditional Chinese
  and Ukrainian.
- Terminology follows the game's own official translations.

Technical
- Interface only. No gameplay data is modified and saved games are unaffected.
- Implemented by decorating the game's panels and patching the registered map layer
  in memory, rather than overwriting any game files.
```

## Uwagi praktyczne (nie do wklejania)

- **Ukraiński** jest dostarczony pod kodem `ru_RU` — gracz z grą ustawioną na rosyjski
  zobaczy mod po ukraińsku. Civ VII nie ma osobnej lokalizacji ukraińskiej
  (patrz [23-localization-i18n.md](../knowledge-base/23-localization-i18n.md)).
- Do publikacji potrzebny jest **obrazek podglądu** — dobry kandydat to zrzut panelu
  „Wspólne dochody" obok mapy z czystymi hexami.
- Proponowane tagi: `UI`, `Quality of Life`, `Interface`.
- Changelog **świadomie nie wspomina** o poprawce brakującej linii „Utrzymanie
  specjalistów" — ta próba dawała błędne liczby i została wycofana przed publikacją.
